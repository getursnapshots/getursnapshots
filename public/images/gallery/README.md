# Snap Shots - Wall of Snap Shots Gallery Images

Place your own event, wedding, corporate, and celebration photos into this directory (`/public/images/gallery/`).

## How to Add Your Photos:
1. Copy your photos into this folder:
   - `photo-1.jpg` (or `.png` / `.webp`)
   - `photo-2.jpg`
   - `photo-3.jpg`
   - `photo-4.jpg`
   - `photo-5.jpg`
   - `photo-6.jpg`
   ...and so on.

2. You can also update the image links directly in:
   `src/config/galleryConfig.ts`

3. Supported formats:
   - JPG / JPEG
   - PNG
   - WEBP

Recommended aspect ratio: 4:5 vertical (e.g. 1080x1350 or 1200x1500) for ideal presentation in the continuous marquee.
